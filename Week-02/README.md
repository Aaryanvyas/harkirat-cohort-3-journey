# 📚 Week 02 - JavaScript Fundamentals

This week we introduced programming logic using JavaScript, the scripting language of the browser.

## 📝 What I Studied
- **Variables & Data Types**: `let`, `const`, `var`, strings, numbers, booleans, arrays, and objects.
- **Control Flow**: `if/else` statements, loops (`for`, `while`).
- **Functions**: Declarations, expressions, and arrow functions.
- **Arrays & Methods**: `.push()`, `.pop()`, `.splice()`, and iterating through arrays.

## 💻 What I Coded
- Basic calculators.
- String utility functions.
- Operations on array objects.

## 🧠 Key Learnings
- Use `const` by default, and `let` only if the variable needs to be reassigned. Avoid `var` due to hoisting and scoping issues.
- Splice is mutating: `array.splice(index, count)` modifies the original array directly.
