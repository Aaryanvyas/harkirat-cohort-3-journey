## 🛠️ How to run the projects locally

To run the vanilla web apps locally:
1. Clone this repository to your machine.
2. Open the project folder in VS Code.
3. Open any `index.html` file (e.g. `Week-03/dom/todo-app/index.html`) using the VS Code extension **Live Server**, or simply double-click the file to open it in your browser.
