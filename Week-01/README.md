# 📚 Week 01 - HTML & CSS Foundations

This week was all about laying the foundations of the web: HTML (structure) and CSS (styling).

## 📝 What I Studied
- **HTML5 Semantic Elements**: `header`, `section`, `article`, `footer`, `nav` and why they are important for SEO and accessibility.
- **CSS Selectors & Specificity**: How style rules apply and override each other.
- **Box Model**: Margin, Border, Padding, and Content.
- **CSS Layouts**: Intro to Flexbox (`display: flex`, `justify-content`, `align-items`).

## 💻 What I Coded
- Simple landing pages.
- Standard form inputs.

## 🧠 Key Learnings
- Always use semantic tags rather than generic `div`s when possible.
- Understanding `box-sizing: border-box` is critical to prevent padding from expanding elements.
